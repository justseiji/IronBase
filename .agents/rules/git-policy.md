# Git Execution & Push Policy

## Autonomy & Local Operations
- You are permitted to execute local commands autonomously (e.g. running tests, building, checking git status, staging, and committing).

## Push Approval Requirement
- **NEVER** run `git push` or push changes to `main` (or any remote branch) without first explicitly presenting the commit history / diff summary and receiving the user's direct confirmation in the chat.
